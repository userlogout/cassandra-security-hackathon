# Cassandra Security Hackathon

Проект для трека № 1 Security Engineering хакатона Lite-Invest.

- **Red Team** — оценить границы доступа и контекста Cassandra AI в разрешённых сценариях и подготовить воспроизводимые доказательства на синтетических данных.
- **Green Team** — разработать и проверить контроль доступа к данным счёта, сохранив штатную работу AI и терминала.

## Текущий прогресс

Изучены терминал и Cassandra AI, разобраны критерии жюри и подготовлен план из десяти кейсов. Проведена проверка чтения данных собственного счёта. Подтверждённых нарушений безопасности пока нет. Следующий исследовательский этап — оценка изоляции двух разрешённых тестовых профилей с синтетическими записями.

| Каталог | Содержимое |
| --- | --- |
| `docs/` | [Обзор](docs/cassandra-research.md), [диагностика AI](docs/cassandra-ai-diagnostics.md), [план тестирования](docs/cassandra-ai-test-plan.md), [анализ критериев](docs/security-criteria-analysis.md) и [обезличенные результаты проверки счёта](docs/account-security-test-results.md). |
| `tests/` | Тесты и синтетические данные. |
| `defense/` | Прототипы и материалы защитного решения. |
| `evidence/` | Проверенные материалы для воспроизведения. |

Каждый завершённый этап оформляется отдельным коммитом. Перед отправкой изменений проверяются секреты, персональные данные и сведения о реальных счетах. Для последующих отправок требуется подтверждение владельца.
