# Диагностика Cassandra AI

21 ноября 2026 года. Осмотр через Playwright MCP в текущей авторизованной сессии. Открыта штатная вкладка Cassandra AI, просмотрены DOM, консоль и журнал уже выполненных браузером запросов. Настройки сайта, данные аккаунта, заголовки и cookies не редактировались. Тела ответов и значения параметров URL в отчёт не включены.

## Почему область пустая

Страница `https://cassandra.lite-invest.com/cassandra-ai` вернула HTTP 200. Фактический `src` iframe указывает на `https://ai.iieasy.ru/widget` и содержит строку запроса, скрытую в отчёте. У iframe другой origin. Запрос документа `GET /widget` виден в сетевом журнале без HTTP-статуса. Вместо виджета Chromium загрузил во фрейме внутренний документ `chrome-error:`. В DOM этого документа обнаружен код **`ERR_TIMED_OUT`**.

Тайм-аут загрузки iframe объясняет пустую область. Точка, на которой прервалось подключение, по журналу не установлена. Маршрутизация AdGuard VPN остаётся возможной причиной, поскольку исключение для основного домена Cassandra не охватывает домен виджета по имени. Также возможны проблемы на сетевом пути или недоступность самого сервиса. В этой попытке не зафиксированы отдельные ошибки DNS, явная блокировка браузером, отказ соединения или HTTP 401/403.

## Два ответа HTTP 404

| Запрос к API Cassandra | Результат | Интерпретация |
| --- | --- | --- |
| `GET /api/Parameter/widget_settings_templates/default/default` | HTTP 404, ошибка загрузки ресурса в консоли | Сервер ответил. Запрошенный шаблон или путь мог отсутствовать. |
| `GET /api/Parameter/profile/default/default` | HTTP 404, ошибка загрузки ресурса в консоли | Сервер ответил. Соседний путь `/api/Parameter/profile/default` вернул 200, поэтому результат относится к конкретному пути. |

Консоль для обоих запросов показала `Failed to load resource: the server responded with a status of 404 ()`. Запрос `GET /api/Authentication/ssoai` вернул 200, после чего в журнале появился запрос виджета. Это подтверждает HTTP-доступность точки SSO, а результат авторизации внутри виджета остаётся неизвестным. Доказательств связи двух 404 с тайм-аутом iframe нет.

## Домены и результат подключения

| Домен | Назначение | Результат подключения | Вероятная причина ошибки |
| --- | --- | --- | --- |
| `cassandra.lite-invest.com` | Оболочка Cassandra AI и ресурсы приложения | HTTP 200 | Ошибки загрузки оболочки не наблюдалось. |
| `api-cassandra.lite-invest.com` | API счёта, авторизации и параметров | HTTP 200 для SSO AI и ряда других запросов. Два пути параметров вернули HTTP 404 | Возможное отсутствие конкретных записей или путей. API доступен. |
| `ai.iieasy.ru` | Документ внешнего AI-виджета `/widget` | HTTP-статус отсутствует, Chromium показал `ERR_TIMED_OUT` | Тайм-аут на сетевом пути или на стороне сервиса. Влияние VPN не проверялось. |
| `fonts.gstatic.com` | Шрифты интерфейса | HTTP 200 | Ошибок загрузки не наблюдалось. |

**Кандидат в исключения AdGuard VPN — `ai.iieasy.ru`.** По текущему замеру оснований добавлять `api-cassandra.lite-invest.com` или `fonts.gstatic.com` нет. Дополнительные домены внутри виджета определить не удалось, потому что его документ не загрузился.
