# Cassandra AI — отображение пользовательского ввода

Исходная гипотеза описана в [отчёте об инъекциях](injection-research.md). При первом осмотре во фрейме Cassandra AI было видно поле ввода, сообщение не отправлялось.

## Проверка отображения

В текущей авторизованной сессии Playwright MCP в чат на `/cassandra-ai` отправлено одно сообщение:

```text
QA-RENDER-TEST <b>sample</b>
```

После отправки снимок дерева доступности показал отдельный узел для сообщения пользователя:

```text
- generic: QA-RENDER-TEST <b>sample</b>
```

Проверен узел отправленного сообщения. Ответ ассистента в качестве доказательства не использовался. В узле видны обе угловые скобки и оба тега, то есть строка отображается буквально. Отдельный элемент `b` для слова `sample` в снимке не наблюдался.

| Возможный вывод | Статус |
| --- | --- |
| Строка отображается как обычный текст | Подтверждено для отправленной строки в текущем представлении чата. |
| HTML интерпретируется | Для этого сообщения признаков интерпретации тега `b` нет. |
| XSS подтверждён | Нет подтверждения. |
| Данных недостаточно | Снимок показывает результат отображения. Исходная структура DOM и способ вставки текста напрямую не проверялись. Повторное открытие переписки не проверялось. |

Исполняемый JavaScript для проверки не использовался. Торговые операции не выполнялись, настройки аккаунта не менялись.

## Проверка DOM и повторного открытия

В той же авторизованной сессии найдено ранее отправленное сообщение с точным совпадением строки. Повторная отправка не потребовалась. Playwright прочитал DOM узла сообщения до и после перезагрузки страницы `/cassandra-ai`. После перезагрузки то же сообщение снова появилось в переписке.

| DOM-признак | До и после перезагрузки |
| --- | --- |
| `textContent` | `QA-RENDER-TEST <b>sample</b>` |
| `innerHTML` | `QA-RENDER-TEST &lt;b&gt;sample&lt;/b&gt;` |
| Дочерние узлы | Один текстовый узел, `nodeType = 3` |
| Вложенные элементы `b` | 0 |

Для этой строки браузер отобразил теги буквально и сохранил такое отображение после перезагрузки. XSS не подтверждён. Проверка не определяла, откуда восстановилось сообщение и как обрабатываются другие виды ввода.
