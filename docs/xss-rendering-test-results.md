# Cassandra AI — отображение пользовательского ввода

Исходная гипотеза описана в [отчёте об инъекциях](injection-research.md). В текущем браузере Playwright MCP открылась страница `/cassandra-ai`. В снимке дерева доступности во вложенном фрейме виден текстовый редактор чата с подсказкой «Спросите или скажите команду». Это наблюдение относится к полю ввода.

Проверка отправкой HTML-подобного ввода в рабочее приложение не проводилась. Тестовое сообщение не создано, DOM отправленного сообщения и повторное открытие переписки не проверены. Дерево доступности само по себе не показывает, находится ли строка в текстовом узле или содержит элемент `b`.

| Возможный вывод | Статус |
| --- | --- |
| Строка отображается буквально как текст | Не проверено. |
| HTML интерпретируется | Не проверено. Элемент `b`, созданный из пользовательского ввода, не наблюдался. |
| XSS подтверждён | Нет подтверждения. Даже наличие элемента `b` показало бы только обработку разметки. |
| Данных недостаточно | Зафиксировано только наличие поля ввода. Сохранение сообщения и способ его отображения неизвестны. |
